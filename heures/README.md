# Mes heures Allin (version test pour la base)

Uniquement la feuille d'heures : pas de frais, pas de fiches OT, pas d'IA, pas de compte.

- Les données restent **sur le téléphone de chacun** (stockage du navigateur). Rien n'est envoyé sur Internet.
- Installable sur l'écran d'accueil, marche sans réseau.
- PDF de la semaine identique à la feuille papier : impression, mail ou partage depuis le téléphone.
- Sauvegarde / restauration par fichier dans « Mon profil ».

Fichiers : `index.html` (l'appli), `sw.js` + `manifest.json` + `icons/` (installation, hors ligne), `lib/` (jsPDF 2.5.1).
Le dossier est autonome : il peut être copié tel quel sur un autre hébergement (serveur du groupe, par exemple).

En ligne : https://thirakor.github.io/Mes-feuilles-Allin/heures/
